Anyway, here's a quick readme bit for the pack.


	'All Split' contains no tilesets. Every sprite is its own file.
	

	'Full Sprite Sheets No Padding' contains all the assets inside appropriate tile sheets. 
		Each tile is 8x8, so you should use this in your game engine to split the tiles.
		This sheet is recommended for use in 2D game engines, such as Construct2 or Construct3.
	

	'Full Sprite Sheets With Padding' is exactly the same as No Padding with different import settings.
		When splitting, ensure a pixel size of 8x8, an offset of 1x1, and a padding of 2x2.
		I HIGHLY recommend using this pack if you're using Unity, as it'll help avoid rendering issues with your tiles.
		The issue is explained here (https://www.youtube.com/watch?v=QW53YIjhQsA) if you want to take a look.
		(Also yes the padding sheets will look weird and are strange to edit directly.)
		

	If you're using Unity, I recommend using the pixel perfect camera.
	You should also read this article on how to import the sprites, under the 'Preparing your sprites' section.
	I recommend having 'Pixels Per Unit' at 8. Just makes everything easy to move.
	https://docs.unity3d.com/Packages/com.unity.2d.pixel-perfect@1.0/manual/index.html
